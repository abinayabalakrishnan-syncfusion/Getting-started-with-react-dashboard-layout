# Getting-started-with-react-dashboard-layout

**Repository Description**  
This repository contains a quick‑start React sample that demonstrates how to create static and dynamic dashboards using the Syncfusion React Dashboard Layout component.

The React Dashboard Layout is a grid‑structured layout component that helps create dashboard layouts composed of panels. Dashboard panels act as containers for UI components and can be added either programmatically or dynamically at runtime. Panels support resizing, reordering, dragging, dropping, removal, and insertion, allowing flexible placement of UI elements within the grid.

## Project Overview
The purpose of this project is to help developers understand how to build interactive dashboards using the Syncfusion React Dashboard Layout component. It demonstrates how panel‑based layouts can be configured dynamically to support responsive, customizable dashboard interfaces.

## Features
- Integration of the Syncfusion React Dashboard Layout component  
- Grid‑based dashboard layout system  
- Dashboard panels that support resizing and reordering  
- Drag‑and‑drop functionality for panels  
- Ability to add and remove panels dynamically  
- Support for static and dynamic dashboard scenarios  

## Prerequisites
Ensure the following are installed before running this project:
- NodeJS (latest version recommended)  
- Visual Studio Code  

## Installation and Running the Application
1. Clone the repository.
    ```bash
    git clone https://github.com/SyncfusionExamples/Getting-started-with-react-dashboard-layout.git
    ```
2. Open the project directory in Visual Studio Code.
3. Install the required dependencies using:`npm install`
4. Start the React development server:`npm start`
5. Open your browser and navigate to the URL shown in the terminal (typically `http://localhost:3000`) to view the Dashboard Layout output.

## Usage
Run the application and interact with the dashboard panels to:
- Drag and reposition panels
- Resize panels dynamically
- Add or remove panels at runtime
- Arrange UI components within the dashboard grid
